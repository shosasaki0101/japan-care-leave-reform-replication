# Output Mapping

This document maps the outputs generated by the replication scripts to the empirical results reported in the manuscript.

The replication workflow produces several types of outputs:

- input-validation and sample-construction checks
- intermediate model objects
- appendix-style raw result tables
- formatted main-text tables
- main-text figures

The manuscript’s main findings are reproduced through the outputs generated by `04_run_main_models.R`, `05_run_robustness.R`, `06_compute_marginal_effects_and_export.R`, and `07_build_main_text_tables.R`.

## 1. Input-validation and sample-construction outputs

These outputs are primarily intended for reproducibility checks rather than direct inclusion in the manuscript.

### Generated by `01_load_panel_and_check_inputs.R`

Stored under `out/checks/`:

- `duplicate_prefid_yearmonth.csv`  
  Confirms that the panel contains no duplicated `pref_id × year_month` observations.

- `year_month_range_check.csv`  
  Reports the panel’s observed time range and total number of rows and prefectures.

- `missingness_check.csv`  
  Summarises missing values by variable.

- `blank_string_check.csv`  
  Checks for blank string entries in character variables.

- `check_Yamanashi_201608.csv`  
  Records the observation for Yamanashi in August 2016.

- `check_Saga_201612.csv`  
  Records the observation for Saga in December 2016.

- `basic_summary.csv`  
  Provides descriptive summaries of the main analytical variables in the input panel.

### Generated by `02_construct_contextual_variables.R`

Stored under `out/checks/`:

- `contextual_missing_after_merge.csv`  
  Confirms whether the contextual-indicator file merges cleanly into the analytical panel.

- `contextual_variables_summary.csv`  
  Lists the prefecture-level contextual indicators used in the heterogeneity analysis.

### Generated by `03_prepare_analysis_samples.R`

Stored under `out/checks/`:

- `sample_summary.csv`  
  Summarises the sample sizes of the analysis datasets created after the clean-window restrictions are applied.

Stored under `out/samples/`:

- `ratio_panel_2016cw.csv`  
  Wide prefecture-month panel used for the auxiliary `ln(M/F)` specification.

- `ppml_panel_2016cw_long.csv`  
  Long-format prefecture-month-sex panel used for the PPML models.

These files document the construction of the estimation samples but are not intended as direct manuscript tables.

## 2. Main model outputs

### Generated by `04_run_main_models.R`

Stored under `out/models/`:

- `m_base.rds`  
  Saved model object for the baseline PPML specification.

- `m_het1.rds`  
  Saved model object for the main heterogeneity specification using prefectural male wage premium.

- `m_bread.rds`  
  Saved model object for the supplementary heterogeneity specification using breadwinner exposure.

Stored under `out/tables/`:

- `D1_core_coefficients.csv`  
  Raw coefficient table containing the key estimates from:
  - the baseline PPML model
  - the main male-wage-premium heterogeneity model
  - the supplementary breadwinner-exposure heterogeneity model

This is an appendix-style raw output table rather than a final manuscript table.

## 7. Interpretation of output status

For practical use, the outputs can be interpreted in three tiers.

### Tier 1: Main-text outputs
These are the files intended for direct use in the manuscript.

- `Table1_baseline_clean_window_ppml.csv`
- `Table2_main_heterogeneity_male_wage_premium.csv`
- `Table3_supplementary_heterogeneity_breadwinner_exposure.csv`
- `Table4_robustness_main_wage_premium_result.csv`
- `Figure1_marginal_effects_wagepremium.png`
- `Figure2_marginal_effects_breadwinner_exposure.png`

### Tier 2: Appendix-style empirical outputs
These provide supporting numerical detail behind the main text.

- `D1_core_coefficients.csv`
- `robustness_postwindow_summary.csv`
- `robustness_controls_summary.csv`
- `robustness_lnratio_summary.csv`
- `D3_marginal_effects_male_wage_premium.csv`
- `D3_marginal_effects_breadwinner_exposure.csv`

### Tier 3: Validation and construction outputs
These document the integrity of the analytical panel and the construction of the estimation samples.

- files under `out/checks/`
- files under `out/samples/`

## 8. Scope

The repository reproduces the empirical analysis from the integrated analytical panel and contextual-indicator file included in the repository. It does not reconstruct the analytical panel from the original administrative and statistical source tables. Variable definitions and broader replication notes are documented separately in `docs/codebook.md` and `docs/replication_notes.md`.
